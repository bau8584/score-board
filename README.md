# 체육 점수판

초등 체육 수업용 태블릿 점수판 (일반 / 야구 / 킨볼 / 컬링).
설치 없이 링크로 열고, 홈화면에 추가하면 오프라인에서도 동작합니다.

- 사용: https://bau8584.github.io/score-board/
- 개발 지침과 구조: [CLAUDE.md](./CLAUDE.md)

```
npm install
npm run dev     # 개발 서버
npm test        # 테스트
npm run build   # 빌드
```

`main` 브랜치에 푸시하면 GitHub Actions가 테스트 후 GitHub Pages로 자동 배포합니다.
